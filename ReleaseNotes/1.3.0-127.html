Ataraxia 1.3.0 (127)

Signed with an Apple Development certificate; not notarized by Apple. Apple Silicon, macOS 26 or later.

  • Web Extensions. Settings → Extensions: install recommended extensions directly, or Manifest V2/V3 extensions from a folder or .zip (Install from File…). Each profile has its own extensions, settings and extension data. Extension actions are in each card’s More (…) menu.
  • Recommended Extensions, downloaded from their publishers’ own GitHub releases and checked against reviewed checksums: uBlock Origin Lite 2026.1124.1811, Dark Reader 4.9.135, Immersive Translate 1.35.4 (partly works: translate with ⌥A after allowing it on websites; features that need its Safari app aren’t available).
  • Your choice of websites. An extension can read or change a website only after you allow it there; you can take that back at any time. An extension allowed on a site can read that page, including a password you fill in.
  • Extensions can’t reach the Password Manager, and can’t message other apps (native messaging isn’t supported). Extension stores (Chrome Web Store, Firefox Add-ons, App Store) aren’t supported, and extensions aren’t updated automatically.
